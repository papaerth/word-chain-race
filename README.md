# 끝말잇기 레이스 (Word Chain Race)

7세 아이와 어른이 핸드폰 하나로 즐기는 음성인식 끝말잇기 보드게임.

- 플레이: https://papaerth.github.io/word-chain-race/
- 한국어 / English, 캐릭터 24종, 모두의 마블식 보드(땅 주인·찬스 카드·탈출 퀴즈)
- 단일 HTML 파일 (`index.html`), 외부 서버 없음

## 사전
`dict/` 는 표준국어대사전 기반 공개 단어 목록(acidsound/korean_wordlist)에서 추출한 명사 목록(`nouns.txt`)과 뜻풀이 조각(`def/*.json`)입니다.
